
# Plataforma web de control remoto

## Entregables

1. URL (o IP) y credenciales de acceso a la plataforma.
2. Código fuente.
3. Informe de actividades.

## Requerimientos

| # | Requerimiento | Descripción |
| --- | --- | --- |
| 1 | Acceso remoto | La plataforma debe ejecutarse fuera del dispositivo de control; es decir, no debe funcionar en la tarjeta Raspberry Pi. |
| 2 | Acciones | Debe permitir controlar la iluminación (encenderla, apagarla o regular su intensidad). |
| 3 | Confirmación | Debe confirmar la ejecución de cada acción. |
| 4 | Alerta | Debe contar con un sensor de movimiento que notifique al usuario por correo electrónico. |
| 5 | Autenticación | Solo se debe permitir el acceso a la plataforma con credenciales válidas. |

## Evaluación

- Se verificará que se pueda controlar la iluminación mediante la plataforma (1.5).
- Se verificará que se genere una alerta por correo electrónico cuando el sensor detecte movimiento (1.5).


Estos son los requisitos del proyecto general.
